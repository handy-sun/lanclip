# lanclip

Self-hosted LAN clipboard for sharing text and files across devices.

## Usage

```bash
npx lanclip
```

The server listens on port `9501` by default and creates `config.json` in the current working directory when no config file is provided.

```bash
lanclip /path/to/config.json
```

See the project repository for full configuration and deployment documentation:

https://github.com/handy-sun/lanclip
